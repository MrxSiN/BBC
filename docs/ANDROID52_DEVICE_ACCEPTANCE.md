# Iteration 52 — Android freestanding PIE acceptance preflight

Nine standalone AArch64 ELF fixtures are generated by the new standard-Brainfuck compact relocation and ELF stages, with a shell runner under [`../build/android52_acceptance/`](../build/android52_acceptance/manifest.json). The fixtures cover empty input, ASCII output, sequential and nested loops, NUL/FF binary I/O, EOF-zero, pointer-underflow exit code 2, a 3,028-command transfer program and 320 nesting levels.

These tests are **not device execution evidence**. Only Linux-native BF stage production, `readelf` inspection and an independent Linux-hosted AArch64 instruction simulator have run. Real Android loading could fail because the freestanding `ET_DYN` layout is experimental; no Android loader, SELinux or page-policy compatibility has been established.

Copy the **contents** of `build/android52_acceptance/` into an executable Android device location such as `/data/local/tmp/bfc52` and run `sh run.sh` there. The runner compares raw stdout SHA-256 and process exit status for every fixture. Record the model, API level, ABI, kernel and build fingerprint; retain full stdout/stderr, exit codes and final result manifest. Do not mark platform acceptance until all cases have actual device evidence.

The nine image fixtures are not GmailHideAds, TwitterHideAds or ThreadsHideAds APKs. The projects' original eleven Brainfuck policy programs, JNI/DSO runtime contract, frame and callback behavior and full APK build/test gates remain outstanding.
