## Commits and pull requests

- **Never add Claude as a contributor.** Commits are authored and committed by the user's git
  identity. No `Co-Authored-By: Claude …`, `Claude-Session:` or other Claude attribution lines in
  commit messages, PR descriptions or comments, and never `noreply@anthropic.com` as author or committer.
- **Pull request titles are plain English.** Say what the change does, e.g. "Add baseline benchmark
  and require BBC to use XAX's production driver". Never a branch name, ticket id or session id.
- **Pull request descriptions are easy to read.** Start with a short summary of what changed and why,
  then one section per change in plain words, then any known gaps or follow-ups. Explain
  abbreviations and numbers a reader needs to judge the change.
